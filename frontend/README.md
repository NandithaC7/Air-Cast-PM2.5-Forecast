# AirCast frontend

Vite, React, and TypeScript interface for the AirCast pages: Overview, Data Explorer, Model Comparison, Predictions, and Methodology.

```bash
npm install
npm run dev
```

The API base URL is `VITE_API_BASE_URL` in `.env`. See `.env.example`. Leave it unset until the backend exists. Request and response shapes are documented in `../docs/API.md`.
